## Featured project

### [ClipWitness](https://github.com/jorgecolonconsulting/clipwitness)
An open-source video-analysis agent, shipped as a Claude Code and Codex plugin. It pulls timestamped claims, on-screen text, and supporting visuals from a video, then uses ffmpeg to match each timecode to the exact frame.

I don't choose models by assumption. My evals showed the cheaper setup got the claims right but gave different results from run to run. So ClipWitness ships both modes with a human in the loop. When accuracy matters, the agent recommends the deeper mode, explains the cost, and lets you decide.
